# TiRT 理论与方法说明

## 1. 模型目标

TiRT（Thermal infrared Radiative Transfer）用于复杂地表热红外方向性辐射传输模拟。模型从地表结构、植被结构、热红外光谱发射率、组分温度和太阳/观测几何出发，计算不同观测方向和不同波段下的：

- 方向辐亮度 `radiance`
- 亮温 `brightness_temperature_K`
- 摄氏亮温 `brightness_temperature_C`
- 叶片、土壤、屋顶、墙体、街道等组分发射率

统一入口为 `run.py`，输入文件为 `input.csv`。输出按“场景组合 × 观测方向 × 波段”展开。

## 2. 热红外辐射基础

TiRT 使用普朗克函数将组分温度转换为单波段热辐射亮度：

```text
B(lambda, T) = c1 / [lambda^5 * (exp(c2 / (lambda * T)) - 1)]
```

其中：

- `lambda`：热红外波长，单位为微米。
- `T`：绝对温度，单位为 K；输入低于 100 时按摄氏度自动加 273.15。
- `c1`、`c2`：代码中使用的辐射常数。

输出亮温由反普朗克函数得到：

```text
T_b = c2 / [lambda * ln(c1 / (L * lambda^5) + 1)]
```

其中 `L` 为方向辐亮度。模型内部先计算组分辐射贡献，再反演为传感器等效亮温。

## 3. 方向性辐射传输框架

一个观测方向上的总辐亮度可概括为：

```text
L_view = sum_i [ epsilon_i,eff(view, sun) * B(lambda, T_i) ]
```

其中：

- `i`：可见组分，如日照土壤、阴影土壤、日照叶片、阴影叶片、屋顶、墙体、街道等。
- `epsilon_i,eff`：在当前观测-太阳几何下的有效组分发射率。
- `T_i`：对应组分温度。

TiRT 的核心不是只做黑体温度换算，而是先由几何光学/冠层辐射传输计算每个组分在观测方向中的可见比例和日照/阴影比例，再合成为方向辐亮度。

默认输出是“仅发射”的离地辐亮度，即黑天空条件，与 HiSTREAM 验证的设置一致。若给出 `sky_temperature_k`（天空下行辐射的等效亮温），则按各向同性天空和基尔霍夫互易加入反射项：

```text
L = sum_i epsilon_i,eff * B(T_i) + (1 - epsilon_eff) * B(T_sky),   epsilon_eff = sum_i epsilon_i,eff
```

`epsilon_eff` 由同一几何下所有组分取同一温度的计算得到，因此组分温度与天空温度都相等时，任何场景都精确返回该温度。

## 4. 植被模型

### 4.1 裸土 `bare`

平坦裸土不产生阴影：太阳在地平线以上时整个表面按日照土壤温度计算，太阳在地平线以下（或在坡面背后）时按阴影土壤温度计算，`L = ε_soil · B(λ, T_soil)`。若启用 `hapke_enable=1`，会使用 Hapke/Thapke 型方向性修正，让土壤有效发射率随观测天顶角变化。单次散射反照率 `w` 由输入的半球发射率反解，保证方向发射率在半球上的积分等于输入值（基尔霍夫一致；例如 ε=0.955、`hapke_K`=1 时 w=0.181）。该修正同样作用于植被下方的可见土壤（坡面用局地观测天顶角），但不作用于城市街道。

### 4.2 均质植被 `hom`

均质植被使用解析冠层模型，计算土壤和叶片在观测方向上的可见比例，并结合热点效应区分日照/阴影部分。解析模型和多次散射系数基于球形叶倾角分布，叶片投影系数固定为 `G = 0.5`；输入文件中的 `G`、`lidfa`、`lidb`、`height`、`leaf_width` 只供 TIRTEB 使用，方向模型不读取。主要参数包括：

- `lai`：叶面积指数。
- `hspot`：热点参数。
- `emissivity_leaf`、`emissivity_soil`：叶片和土壤发射率。
- `leaf_sunlit_c`、`leaf_shaded_c`、`soil_sunlit_c`、`soil_shaded_c`：组分温度。

### 4.3 垄行植被 `row`

垄行模型在均质冠层基础上加入行宽、行距、行高和行向。模型根据观测方位、太阳方位与行向的相对关系，计算行间土壤和行体植被的方向性可见比例。主要参数：

- `row_width`
- `row_blank`
- `row_height`
- `row_azimuth`
- `thermal_row_geometry`：默认 `parametric`。垂直垄向截面内，视线穿过垄带的长度是起点位置 x 的分段线性函数，因此土壤可视比例与光照土壤（含叶片尺度热点重叠）按断点精确求和；光照可见叶片对每一深度使用同样的分段解析式，深度方向 8 点 Gauss 求积。`conditioned_corridor`（开放行间通道修正）和 `legacy` 为此前的闭合，可显式选择。平地、坡面、复合地形和城市中的垄行使用同一几何。

### 4.4 离散树冠 `crown`

离散树冠模型把森林表示为一定密度的椭球冠层，计算树冠遮挡、冠层可见比例和背景土壤比例，适用于稀疏林、果园、林地等离散冠层结构。主要参数：

- `crown_rad_a`（别名 `crown_radius`）：树冠水平半径
- `crown_rad_b`：树冠垂直半轴（不再接受有歧义的 `crown_width` 别名）
- `crown_density`：单位面积株数
- `crown_height`：冠底高度，冠心高度 H_c = `crown_height` + `crown_rad_b`
- `thermal_crown_geometry`：默认 `parametric`；`clumping_dual`（整冠内/外双热点）与 `legacy` 为此前的闭合，可显式选择。

默认的参数化方案把树冠视为泊松分布的浑浊椭球（冠内消光 k = 0.5·LAI /(crown_density·V)），四组分比例都是闭式表达：

- 土壤可视比例 `exp(-crown_density · J_v)`，J = A·[1 − 2(1 − (1+x)e^{−x})/x²]，x = 1.5·k·l̄，A 为投影面积，l̄ = V/(A cosθ) 为平均弦长。椭球任意方向的平行弦长为 l_max·√(1−ρ²)，ρ² 在投影面上均匀分布，因此该式是精确解。
- 光照土壤 `P_soil · exp(-crown_density · (J_s − K))`。K 为同一树冠同时挡住观测与太阳两条射线的共同遮挡：两条投影（取等面积圆）的透镜重叠面积 × (1 − t_v − t_s + t_vs)，投影中心距离为 H_c·|tanθ_v ê_v − tanθ_s ê_s|，t_vs 含叶片尺度热点相关并不超过单条透过率。精确热点处 K = J_s，光照土壤等于土壤可视比例。
- 光照叶片：把椭球按 z·(rcr/hcr) 映射为球后求观测—太阳相位角 γ，迎光可见比例 ((1+cosγ)/2)^p，背光部分乘以穿透冠体的太阳透过率，再乘以可见层有限厚度因子；系数 (0.567, 0.369, 1.595) 对泊松冠精确积分标定一次，未用 HiSTREAM 调参。

`hspot` 为叶片大小与冠层厚度之比，树冠应取叶片大小 / 树冠高度（例如 0.15 m 叶片、6 m 树冠取 0.025）。

### 4.5 冠层多次散射

所有植被类型使用同一个叶片源多次散射闭合：

```text
ε_ms = [g_v (1 - M) ρ_s + (1 - α(θ_v)) (1 - g_v M)(1 - g_v) ρ_l] (1 - ρ_l)
```

均质和垄行冠层取 `g_v = exp(-0.5 LAI/μ_v)`、`M = exp(-0.825 LAI)`。离散树冠的 `g_v` 取树冠模型自身的视向间隙率，`M` 取树冠半球间隙率映射到等效均质 LAI 后的拟合值，因此树冠密度趋于 0 时散射项连续趋于 0。α 按 10° 表线性插值（80° 以上取 80° 的值）。直射与散射之和超过 1 时按剩余发射率预算缩放散射项。

## 5. 地表模型

### 5.1 平面 `plane`

平面地表直接调用植被/裸土模型，是最基础的方向性热红外场景。

### 5.2 单坡 `slope`

坡面模型先把全局太阳和观测方向转换为坡面局地坐标，再计算局地几何下的辐射结果。均质、垄行和离散树冠都视为平行于坡面的冠层，在局地几何中计算（垄向同样换算到局地坐标），LAI 和株密度按坡面面积计；这相当于树木垂直于坡面生长，HiSTREAM 单坡验证场景采用同样设定。太阳位于坡面背后时所有组分按阴影处理。相对坡面法线的观测天顶角大于 89° 的方向从输出中省略，并给出 `BackfaceOmittedWarning`（GUI 接口返回 `omitted_backface` 计数）。

### 5.3 复合地形 `terrain`

复合地形模型把地形表示为高度、半径和密度定义的锥体单元集合，计算地形遮挡、可视比例和日照/阴影比例。裸地使用 `Terrain`；`hom`、`row`、`crown` 都使用 `TerrainForest`：锥面坡度 β = atan(h/r)，冠层在每个面元的局地坐标中计算（LAI 与株密度按水平面积计，即面元上取 `lai·cosβ`、`std·cosβ`），自遮挡按面元朝向处理，他山遮挡单独计入。森林默认 `forest_transport=legacy`（地形互反射 + 冠层散射，地形密度趋于 0 时精确退化为平地）；`reciprocal_exchange` 为可选的 4 状态互易交换。

参数支持分号数组，例如多层地形：

```text
terrain_height = 10;20;30
terrain_radius = 5;10;15
terrain_density = 0.001;0.0005;0.0002
```

### 5.4 城市 `urban`

城市模型把建筑表示为长度、宽度、高度、密度和方位角定义的建筑单元，区分屋顶、墙体、街道的可见和日照/阴影贡献，可与 `hom`、`row`、`crown` 组合。建筑占地比例 `Σ density·length·width` 必须小于 1。所有方位角差统一折叠到 [0°, 180°]，建筑方位 0° 与 360° 等价，镜像几何给出相同结果。

### 5.5 地形与城市的多次散射

地形单元和建筑之间的发射—反射交换按布尔随机场（Boolean field）处理：

- 地形单元的上/下半球交换使用朗伯视因子加权，交换比例已截断归一（近地平线方向不出现负分量）。裸地中，山体发射经坡面和地面反射、地面发射经坡面反射，各自使用发射组分和反射组分自己的发射率。
- 散射墙体发射的日照份额按路径区分：墙—墙路径由发射面元的朝向（是否朝向太阳）与接收面元的视因子推导，经地面/屋顶反射的路径取朝向平均，再乘以面元间的相互遮阴因子。
- 植被散射分两步：先在每个表面上计算冠层内部的叶片源多次散射（4.5 节，锥面用面元局地角度和 `lai·cosβ`；城市中作用于可见街道部分，并按建筑阴影划分日照/阴影），再把“冠层 + 背景”作为混合表面参与地形或建筑之间的交换。地形或建筑密度趋于 0 时，结果精确退化为对应的平地冠层。

## 6. 波段与光谱

TiRT 支持直接输入波段和发射率数组，也支持从文件读取并插值到目标波段。

直接模式：

```text
wavelengths = 8.0;10.5;12.0
emissivity_leaf = 0.975;0.985;0.980
```

文件模式：

- 叶片光谱：`wavelength leaf_emissivity`
- 土壤光谱：`wavelength soil_emissivity`
- 城市光谱：`wavelength roof_emissivity wall_emissivity street_emissivity`

每组直接输入的发射率数量必须与 `wavelengths` 数量一致。

## 7. 观测几何

`geometry_mode` 控制观测方向来源：

- `0`：使用 `vza` 和 `vaa` 的笛卡尔组合或 zip 配对。
- `1`：自动生成太阳主平面和垂直主平面。
- `2`：从 `geometry_file` 读取观测方向。
- `3`：生成主平面方向，并可追加半球方向、文件方向或手动方向。

几何文件每行支持：

```text
vza vaa
vza vaa sza saa
```

角度单位均为度。

## 8. 输出字段

主要输出字段：

| 字段 | 含义 |
|---|---|
| `scenario_id` | 批量参数组合编号 |
| `scenario_label` | 批量参数组合标签 |
| `surface_model` | 地表模型 |
| `vegetation_model` | 植被模型 |
| `wavelength_um` | 波长，单位 um |
| `vza`、`vaa` | 观测天顶角、观测方位角 |
| `sza`、`saa` | 太阳天顶角、太阳方位角 |
| `raa` | 相对方位角 |
| `radiance` | 方向辐亮度 |
| `brightness_temperature_K` | 亮温，单位 K |
| `brightness_temperature_C` | 亮温，单位摄氏度 |

## 9. 数值稳定处理

为避免奇异几何造成无效输出，模型对若干边界情况做了保护：

- 天顶角接近 0 或 90 度时，内部计算使用有限角度近似；太阳与观测都垂直时阴影重叠比取 0。
- 城市 nadir 观测中，观测方位物理上无定义，内部统一到太阳方位，避免虚假的方位差异。
- 坡面背面观测会被省略并给出警告。
- 非有限的辐射或亮温不会输出到 GUI 和绘图模块。

## 10. 模型适用边界

TiRT 适合单点或小场景方向性热红外模拟，重点是结构和几何造成的方向性差异。若要用于大区域制图，应额外准备逐像元输入、地表分类、组分温度反演和传感器响应函数等前处理。

# TiRT 理论与方法说明

## 1. 模型目标

TiRT（Thermal infrared Radiative Transfer）用于复杂地表热红外方向性辐射传输模拟。模型从地表结构、植被结构、热红外光谱发射率、组分温度和太阳/观测几何出发，计算不同观测方向和不同波段下的：

- 方向辐亮度 `radiance`
- 亮温 `brightness_temperature_K`
- 摄氏亮温 `brightness_temperature_C`
- 叶片、土壤、屋顶、墙体、街道等组分发射率

统一入口为 `run.py`，输入文件为 `input.csv`。输出按“场景组合 × 观测方向 × 波段”展开。

## 2. 热红外辐射基础

TiRT 使用普朗克函数将组分温度转换为单波段热辐射亮度：

```text
B(lambda, T) = c1 / [lambda^5 * (exp(c2 / (lambda * T)) - 1)]
```

其中：

- `lambda`：热红外波长，单位为微米。
- `T`：绝对温度，单位为 K；输入低于 100 时按摄氏度自动加 273.15。
- `c1`、`c2`：代码中使用的辐射常数。

输出亮温由反普朗克函数得到：

```text
T_b = c2 / [lambda * ln(c1 / (L * lambda^5) + 1)]
```

其中 `L` 为方向辐亮度。模型内部先计算组分辐射贡献，再反演为传感器等效亮温。

## 3. 方向性辐射传输框架

一个观测方向上的总辐亮度可概括为：

```text
L_view = sum_i [ epsilon_i,eff(view, sun) * B(lambda, T_i) ]
```

其中：

- `i`：可见组分，如日照土壤、阴影土壤、日照叶片、阴影叶片、屋顶、墙体、街道等。
- `epsilon_i,eff`：在当前观测-太阳几何下的有效组分发射率。
- `T_i`：对应组分温度。

TiRT 的核心不是只做黑体温度换算，而是先由几何光学/冠层辐射传输计算每个组分在观测方向中的可见比例和日照/阴影比例，再合成为方向辐亮度。

## 4. 植被模型

### 4.1 裸土 `bare`

平坦裸土不产生阴影：太阳在地平线以上时整个表面按日照土壤温度计算，太阳在地平线以下（或在坡面背后）时按阴影土壤温度计算，`L = ε_soil · B(λ, T_soil)`。若启用 `hapke_enable=1`，会使用 Hapke/Thapke 型方向性修正，让土壤有效发射率随观测天顶角变化。单次散射反照率 `w` 由输入的半球发射率反解，保证方向发射率在半球上的积分等于输入值（基尔霍夫一致）。

### 4.2 均质植被 `hom`

均质植被使用解析冠层模型，计算土壤和叶片在观测方向上的可见比例，并结合热点效应区分日照/阴影部分。解析模型和多次散射系数基于球形叶倾角分布，叶片投影系数固定为 `G = 0.5`，输入其他 `G` 值会报错。主要参数包括：

- `lai`：叶面积指数。
- `hspot`：热点参数。
- `emissivity_leaf`、`emissivity_soil`：叶片和土壤发射率。
- `leaf_sunlit_c`、`leaf_shaded_c`、`soil_sunlit_c`、`soil_shaded_c`：组分温度。

### 4.3 垄行植被 `row`

垄行模型在均质冠层基础上加入行宽、行距、行高和行向。模型根据观测方位、太阳方位与行向的相对关系，计算行间土壤和行体植被的方向性可见比例。主要参数：

- `row_width`
- `row_blank`
- `row_height`
- `row_azimuth`

### 4.4 离散树冠 `crown`

离散树冠模型把森林表示为一定密度的椭球冠层。模型计算树冠遮挡、冠层可见比例和背景土壤比例，适用于稀疏林、果园、林地等离散冠层结构。主要参数：

- `crown_rad_a`：树冠水平半轴
- `crown_rad_b`：树冠垂直半轴
- `crown_density`
- `crown_height`：树干高度（冠底高度）

树冠中心按泊松分布（布尔模型），冠内叶片按浑浊介质处理（体密度 `lai / (crown_density · V)`，V 为椭球体积）。四组分比例按以下方式精确积分：

- 土壤可视比例 `exp(-crown_density · ∫(1 - T_v))`：对椭球投影面内的平行弦长积分树冠透过率 T_v，而不是对平均光学厚度取指数（后者会低估林下土壤的比例）。
- 光照可视土壤：对每个树冠位置计算观测和太阳两条射线的联合透过率再积分，因此包含树冠尺度的阴影与可视区域重叠；叶片尺度热点用 `hspot`（叶片大小 / 树冠厚度 2·`crown_rad_b`）按 Kuusk 形式加入。
- 叶片：对树冠体积积分“自身树冠内透过率 × 其他树冠的泊松间隙”，其总和等于 1 - 土壤可视比例，光照叶片取同一积分中的太阳-观测联合间隙。

光照土壤比例依赖树冠离地高度，平面、坡面、复合地形和城市中的离散树冠都使用 `crown_height` 作为冠底高度。

## 5. 地表模型

### 5.1 平面 `plane`

平面地表直接调用植被/裸土模型，是最基础的方向性热红外场景。

### 5.2 单坡 `slope`

坡面模型先把全局太阳和观测方向转换为坡面局地坐标，再计算局地几何下的辐射结果。均质和垄行冠层视为平行于坡面的冠层层，在局地几何中计算（垄向同样换算到局地坐标）；太阳位于坡面背后时所有组分按阴影处理。离散树冠使用竖直树木的坡面树冠模型。背坡不可见或近水平奇异位置会被过滤，以避免无效辐射记录进入输出。

### 5.3 复合地形 `terrain`

复合地形模型把地形表示为高度、半径和密度定义的地形单元集合，计算地形遮挡、可视比例和日照/阴影比例。可与裸土或离散树冠组合；选择 `hom` 或 `row` 时会给出警告并按离散树冠计算。

参数支持分号数组，例如多层地形：

```text
terrain_height = 10;20;30
terrain_radius = 5;10;15
terrain_density = 0.001;0.0005;0.0002
```

### 5.4 城市 `urban`

城市模型把建筑表示为长度、宽度、高度、密度和方位角定义的建筑单元，区分屋顶、墙体、街道的可见和日照/阴影贡献。可与离散树冠组合形成城市-植被耦合场景；`hom`/`row` 同样按离散树冠计算并给出警告。

### 5.5 地形与城市的多次散射

地形单元和建筑之间的发射—反射交换按布尔随机场（Boolean field）处理，结果已用高度场 Monte Carlo 光线追踪核对：

- 面元遮挡使用面元所在高度以上的遮挡体，锥体侧面按高度带 `(1 − z/h)` 加权并用精确投影带面积；上/下半球交换使用朗伯视因子（相对面元法线的余弦）加权，街道和屋顶按余弦加权。默认锥体场面元到天空/地面/其他面元的比例为 0.61/0.16/0.23（Monte Carlo 0.61/0.16/0.23），城市街道 1−SVF 为 0.36（Monte Carlo 0.32）。
- 散射墙体发射的日照份额按路径区分：墙—墙路径由发射面元的朝向（是否朝向太阳）与接收面元的视因子推导，经地面/屋顶反射的路径取朝向平均，再乘以面元间的相互遮阴因子。
- 地形植被（`Terrain_Veg`）启用了相同的散射项：每个表面视为土壤与树冠的混合，发射率按半球冠层间隙组合，反射率按传感器所见组分组合；锥体面元上的树冠在面元局地坐标中计算（`lai·cosβ`、`std·cosβ`，β 为面元坡度）。
- 植被散射分两步：先在每个表面上计算森林与背景土壤（或街道）之间的散射（与平地树冠模型相同的 `emissivity_scatter_analytical`，锥面用面元局地角度和 `lai·cosβ`，按该表面的可见比例加权；处于地形阴影或背阳面上的部分全部计为阴影叶片；城市中植被为单一温度组分），再把“森林 + 背景”作为混合表面参与上面的地形或建筑之间的交换。

## 6. 波段与光谱

TiRT 支持直接输入波段和发射率数组，也支持从文件读取并插值到目标波段。

直接模式：

```text
wavelengths = 8.0;10.5;12.0
emissivity_leaf = 0.975;0.985;0.980
```

文件模式：

- 叶片光谱：`wavelength leaf_emissivity`
- 土壤光谱：`wavelength soil_emissivity`
- 城市光谱：`wavelength roof_emissivity wall_emissivity street_emissivity`

每组直接输入的发射率数量必须与 `wavelengths` 数量一致。

## 7. 观测几何

`geometry_mode` 控制观测方向来源：

- `0`：使用 `vza` 和 `vaa` 的笛卡尔组合或 zip 配对。
- `1`：自动生成太阳主平面和垂直主平面。
- `2`：从 `geometry_file` 读取观测方向。
- `3`：生成主平面方向，并可追加半球方向、文件方向或手动方向。

几何文件每行支持：

```text
vza vaa
vza vaa sza saa
```

角度单位均为度。

## 8. 输出字段

主要输出字段：

| 字段 | 含义 |
|---|---|
| `scenario_id` | 批量参数组合编号 |
| `scenario_label` | 批量参数组合标签 |
| `surface_model` | 地表模型 |
| `vegetation_model` | 植被模型 |
| `wavelength_um` | 波长，单位 um |
| `vza`、`vaa` | 观测天顶角、观测方位角 |
| `sza`、`saa` | 太阳天顶角、太阳方位角 |
| `raa` | 相对方位角 |
| `radiance` | 方向辐亮度 |
| `brightness_temperature_K` | 亮温，单位 K |
| `brightness_temperature_C` | 亮温，单位摄氏度 |

## 9. 数值稳定处理

为避免奇异几何造成无效输出，模型对若干边界情况做了保护：

- 天顶角接近 0 或 90 度时，内部计算使用有限角度近似。
- 城市 nadir 观测中，观测方位物理上无定义，内部统一到太阳方位，避免虚假的方位差异。
- 坡面背面观测会被过滤。
- 非有限的辐射或亮温不会输出到 GUI 和绘图模块。

## 10. 模型适用边界

TiRT 适合单点或小场景方向性热红外模拟，重点是结构和几何造成的方向性差异。若要用于大区域制图，应额外准备逐像元输入、地表分类、组分温度反演和传感器响应函数等前处理。

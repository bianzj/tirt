# TiRT 理论与方法说明

## 1. 模型目标

TiRT（Terrestrial Inhomogeneous Radiative Transfer，陆表非均质辐射传输）用于陆表非均质辐射传输模拟，热红外方向性辐射传输是其核心。模型从地表结构、植被结构、热红外光谱发射率、组分温度和太阳/观测几何出发，计算不同观测方向和不同波段下的：

- 方向辐亮度 `radiance`
- 亮温 `brightness_temperature_K`
- 摄氏亮温 `brightness_temperature_C`
- 叶片、土壤、屋顶、墙体、街道等组分发射率

统一入口为 `run.py`，输入文件为 `input.csv`。输出按“场景组合 × 观测方向 × 波段”展开。

## 2. 热红外辐射基础

TiRT 使用普朗克函数将组分温度转换为单波段热辐射亮度：

```text
B(lambda, T) = c1 / [lambda^5 * (exp(c2 / (lambda * T)) - 1)]
```

其中：

- `lambda`：热红外波长，单位为微米。
- `T`：绝对温度，单位为 K；输入低于 100 时按摄氏度自动加 273.15。
- `c1`、`c2`：代码中使用的辐射常数。

输出亮温由反普朗克函数得到：

```text
T_b = c2 / [lambda * ln(c1 / (L * lambda^5) + 1)]
```

其中 `L` 为方向辐亮度。模型内部先计算组分辐射贡献，再反演为传感器等效亮温。

## 3. 方向性辐射传输框架

一个观测方向上的总辐亮度可概括为：

```text
L_view = sum_i [ epsilon_i,eff(view, sun) * B(lambda, T_i) ]
```

其中：

- `i`：可见组分，如日照土壤、阴影土壤、日照叶片、阴影叶片、屋顶、墙体、街道等。
- `epsilon_i,eff`：在当前观测-太阳几何下的有效组分发射率。
- `T_i`：对应组分温度。

TiRT 的核心不是只做黑体温度换算，而是先由几何光学/冠层辐射传输计算每个组分在观测方向中的可见比例和日照/阴影比例，再合成为方向辐亮度。

默认输出是“仅发射”的离地辐亮度，即黑天空条件，与 HiSTREAM 验证的设置一致。若给出 `sky_temperature_k`（天空下行辐射的等效亮温），则按各向同性天空和基尔霍夫互易加入反射项：

```text
L = sum_i epsilon_i,eff * B(T_i) + (1 - epsilon_eff) * B(T_sky),   epsilon_eff = sum_i epsilon_i,eff
```

`epsilon_eff` 由同一几何下所有组分取同一温度的计算得到，因此组分温度与天空温度都相等时，任何场景都精确返回该温度。

## 4. 植被模型

### 4.0 冠层闭合级别与默认路径

`canopy_closure` 决定冠层实现，缺省为 `standard`；可选 `upgrade`、`legacy`。它与地形/城市宏观交换的选项不是同一个开关。

| 闭合 | 热红外直接项的四组分几何 | 冠层内部散射 / 短波 |
|---|---|---|
| `standard`（默认） | 均质/垄行采用 CI 透过率、双尺度热点土壤重叠及覆盖相内双层日照叶片近似；树冠土壤采用泊松椭球重叠，叶片也用覆盖相近似 | 热红外采用节点散射；短波一次散射与热红外共用同一四组分，高阶散射用同一节点算子（第 4.6 节） |
| `upgrade` | 均质采用 Beer–Lambert 与联合透过率积分；垄行采用参数化截面；树冠采用泊松椭球四组分公式 | 与 `standard` 形式相同，四组分换为本级别的几何 |
| `legacy` | 先前各植被模型及其几何选项 | 保留先前经验散射、有效层或专用树冠光学分支；不能套用当前标准短波的物理保证 |

因此，配置中保留 `thermal_row_geometry=parametric` 并不表示默认 `standard` 使用参数化垄行四组分；该选项控制旧路径。`thermal_crown_geometry`、`optical_crown_geometry`、`optical_crown_source` 等旧分支参数也不能覆盖已经选择的标准冠层算子。显式非空 `row_closure=legacy/conditioned/reference` 是平地垄行的单独覆盖路径，需与缺省 `row_closure` 留空区分。

实现入口见 [canopy_closure.py](../base/canopy_closure.py) 和 [node_radiosity.py](../base/node_radiosity.py)。

### 4.1 裸土 `bare`

平坦裸土不产生阴影：太阳在地平线以上时整个表面按日照土壤温度计算，太阳在地平线以下（或在坡面背后）时按阴影土壤温度计算，`L = ε_soil · B(λ, T_soil)`。若启用 `hapke_enable=1`，会使用 Hapke/Thapke 型方向性修正，让土壤有效发射率随观测天顶角变化。单次散射反照率 `w` 由输入的半球发射率反解，保证方向发射率在半球上的积分等于输入值（基尔霍夫一致；例如 ε=0.955、`hapke_K`=1 时 w=0.181）。该修正同样作用于植被下方的可见土壤（坡面用局地观测天顶角），但不作用于城市街道。

### 4.2 均质植被 `hom`

均质植被计算土壤和叶片的方向可见比例，并通过热点几何区分热红外日照/阴影组分。方向冠层闭合采用球形叶倾角分布，叶片投影系数固定为 `G = 0.5`；修改 `G`、`lidfa`、`lidb` 不会改变该方向闭合。`standard` 与 `upgrade` 的四组分差异见 4.0 节；短波的球形叶片相函数与热点处理见 4.6 节。主要参数包括：

- `lai`：叶面积指数。
- `hspot`：热点参数。
- `leaf_reflectance`、`leaf_transmittance`、`soil_reflectance`：叶片和土壤光学参数（热红外发射率由它们换算，见第 6 节）。
- `leaf_sunlit_c`、`leaf_shaded_c`、`soil_sunlit_c`、`soil_shaded_c`：组分温度。

### 4.3 垄行植被 `row`

垄行模型在均质冠层基础上加入行宽、行距、行高和行向。模型根据观测方位、太阳方位与行向的相对关系，计算行间土壤和行体植被的方向性可见比例。主要参数：

- `row_width`
- `row_blank`
- `row_height`
- `row_azimuth`
- `thermal_row_geometry`：在 `canopy_closure=legacy` 的旧热红外路径中默认 `parametric`；另有 `conditioned_corridor` 和 `legacy`。参数化方法按截面断点积分土壤透过率，并以 8 点 Gauss 深度积分计算可见日照叶片。当前 `standard` 使用 CI 两相覆盖/通道闭合，`upgrade` 的热红外四组分才使用参数化参考截面。短波一次散射使用与热红外相同级别的四组分。坡面/复合地形中的垄向在局地坐标中处理。

### 4.4 离散树冠 `crown`

离散树冠模型把森林表示为一定密度的椭球冠层，计算树冠遮挡、冠层可见比例和背景土壤比例，适用于稀疏林、果园、林地等离散冠层结构。主要参数：

- `crown_rad_a`（别名 `crown_radius`）：树冠水平半径
- `crown_rad_b`：树冠垂直半轴（不再接受有歧义的 `crown_width` 别名）
- `crown_density`：单位面积株数
- `crown_height`：冠底高度，冠心高度 H_c = `crown_height` + `crown_rad_b`
- `thermal_crown_geometry`：在 `canopy_closure=legacy` 中默认 `parametric`；`clumping_dual` 和 `legacy` 为旧路径的其他选项。标准级别由 4.0 节的冠层闭合决定四组分。

泊松浑浊椭球的参数化几何取冠内消光 k = 0.5·LAI /(crown_density·V)。以下土壤几何用于标准树冠闭合；参数化日照叶片公式用于 `upgrade` 或显式旧参数化路径，`standard` 的日照叶片改用覆盖相双层近似：

- 土壤可视比例 `exp(-crown_density · J_v)`，J = A·[1 − 2(1 − (1+x)e^{−x})/x²]，x = 1.5·k·l̄，A 为投影面积，l̄ = V/(A cosθ) 为平均弦长。椭球任意方向的平行弦长为 l_max·√(1−ρ²)，ρ² 在投影面上均匀分布，因此该式是精确解。
- 光照土壤 `P_soil · exp(-crown_density · (J_s − K))`。K 为同一树冠同时挡住观测与太阳两条射线的共同遮挡：两条投影（取等面积圆）的透镜重叠面积 × (1 − t_v − t_s + t_vs)，投影中心距离为 H_c·|tanθ_v ê_v − tanθ_s ê_s|，t_vs 含叶片尺度热点相关并不超过单条透过率。精确热点处 K = J_s，光照土壤等于土壤可视比例。
- 光照叶片：把椭球按 z·(rcr/hcr) 映射为球后求观测—太阳相位角 γ，迎光可见比例 ((1+cosγ)/2)^p，背光部分乘以穿透冠体的太阳透过率，再乘以可见层有限厚度因子；系数 (0.567, 0.369, 1.595) 对泊松冠精确积分标定一次，未用 HiSTREAM 调参。

热红外几何中的 `hspot` 表示叶片大小与冠层厚度之比，例如 0.15 m 叶片、6 m 树冠可取 0.025。短波一次散射使用同一四组分，因此两个波段的热点几何相同。

### 4.5 热红外四组分与节点散射

当前 `standard` / `upgrade` 的四组分顺序为日照土壤、阴影土壤、日照叶片、阴影叶片。设其可见比例为 P_i，直接发射权重为 P_i·ε_i；节点辐射度计算反射后到达传感器的附加权重，再分别乘以对应组分的普朗克辐亮度。节点出射功率通过线性方程求全阶内部交换，不使用下面的旧经验 ε_ms 公式。

内部节点离散为：均质 `hom3`（土壤 + 上下两个冠层层）、垄行 `row3`（覆盖土壤 + 开放土壤 + 一个冠层层）、树冠 `crown2`（混合土壤 + 一个冠层层）。树冠当前没有启用覆盖/开放土壤的分裂离散，也不解析冠内垂直温度剖面。土壤节点容量为单位地面上的面积比，叶片节点容量为 `A_leaf = 4 G LAI_node`；交换因子满足 `A_i F_ij = A_j F_ji`。叶片保留上/下行状态，双朗伯反/透射在两个方向之间分配功率，几何本身采用球形叶片 `G=0.5`。

节点矩阵满足内部互易与预算约束，并不自动证明热红外四组分直接项和节点能量预算的所有非等温半球积分完全相同；它们仍是有限组分、有限节点近似。TiRT/TIRTEB 共用方向接口的一致性也不等于独立辐射或温度验证。

仅对 `canopy_closure=legacy` 的先前冠层叶片源闭合，有下列经验形式：

```text
ε_ms = [g_v (1 - M) ρ_s + (1 - α(θ_v)) (1 - g_v M)(1 - g_v) ρ_l] (1 - ρ_l)
```

旧均质/垄行闭合取 `g_v = exp(-0.5 LAI/μ_v)`、`M = exp(-0.825 LAI)`；旧树冠分支以自身方向/半球间隙率构造等效参数。α 来自角度表插值，个别旧路径还按剩余发射率预算缩放散射项。这些经验式及缩放不能用于描述当前标准节点算法。

### 4.6 标准短波：与热红外共用四组分

`standard` / `upgrade` 的短波一次散射直接使用热红外的四组分可见比例 P_i（日照土壤、阴影土壤、日照叶片、阴影叶片，`canopy_closure.fractions`），高阶散射使用热红外同一节点算子（`node_radiosity`）。两个波段共用同一套几何。纯直射 BRF：

```text
BRF_beam = r_s · P_ss + (ρ_leaf · sob + τ_leaf · sof) / k_v · P_ls + R_multi
```

sob、sof 为球形叶倾角分布下的双向散射系数（`vnir.spherical_coefficients`），k_v = 0.5/cos θ_v。日照土壤 P_ss 为太阳/观测射线的联合间隙，精确热点处等于太阳方向间隙 P(s)。R_multi 为节点辐射度的高阶直射散射。均匀各向同性天空使用相同节点的全阶响应：

```text
HDRF = (1 - f_diffuse) I_sunlit BRF_beam + f_diffuse HDRF_isotropic_sky
```

启用 Hapke 时，方向修正只作用于 r_s · P_ss 项。

### 4.7 已知限制与精度

2026-10-26 曾把短波一次散射替换为单独的“零边际互易热点”节点算子；它不再读取四组分，热点处日照土壤从 0.421 降到约 0.255，十场景短波 RMSE 普遍增大 2–4 倍。2026-10-27 已回退到本节形式。当前仍存在以下已知问题（`tests/test_optical_conservation.py`、`tests/test_optical_limits.py` 中对应用例标为预期失败；修复后会以“意外通过”提示）：

- 太阳/观测互易：`standard` 的日照叶片覆盖相双层近似不对称。LAI=2、hspot=0.1、ρ/τ=0.45/0.40、r_s=0.25，太阳 (40°,130°) 与观测 (70°,280°) 对调后，均质 BRF 为 0.378/0.434，垄行 0.390/0.434，树冠 0.319/0.310。日照土壤联合间隙本身是对称的。
- 一次散射与节点能量预算：同一算例直射下的半球积分比节点吸收预算给出的反照率高 0.016–0.033（均质 0.360 对 0.336）。原因之一是节点预算按独立间隙计一次逃逸，未计热点相关带来的额外逃逸。
- 单坡掠射：局地太阳接近坡面地平线时日照叶片项不随 cos 衰减。坡 40°、纯直射下 BRF 在 0.1° 内从约 0.05 跌到 0（sza 49.9° 为 0.0526，50.01° 为 0）。

冻结十场景、670/860 nm/10.5 μm 与 HiSTREAM 的 RMSE 与冻结基准一致（例如均质 860 nm 0.0075 BRF、平地树冠 0.0214、单坡树冠 0.0207、热红外 0.13–0.65 K）；与冻结预测的最大逐点差约 0.0012，来自保留的节点积分网格修改。这是固定组分温度下的方向辐射比较，不验证 TIRTEB 预测温度或通量。

## 5. 地表模型

### 5.1 平面 `plane`

平面地表直接调用植被/裸土模型，是最基础的方向性热红外场景。

### 5.2 单坡 `slope`

坡面模型先把全局太阳和观测方向转换为坡面局地坐标，再计算局地几何下的辐射结果。均质、垄行和离散树冠都视为平行于坡面的冠层，在局地几何中计算（垄向同样换算到局地坐标），LAI 和株密度按坡面面积计；这相当于树木垂直于坡面生长，HiSTREAM 单坡验证场景采用同样设定。太阳位于坡面背后时所有组分按阴影处理。短波单坡 BRF 的分母为水平面总入射（与单坡能量平衡一致）：`R = (1−f)·max(cos i,0)/cos θ_s · R_dir,local + f·(1+cosβ)/2 · R_dif,local`，f 为水平面散射比，局地 R 按坡面入射归一；只计各向同性天空视因子，不计周围地面反射。太阳越过坡面地平线时直射权重随 cos i 趋零，但局地掠射下的日照叶片项不随 cos 衰减，BRF 在 0.1° 内从约 0.05 跌到 0（见 4.7 节）。相对坡面法线的观测天顶角大于 89° 的方向从输出中省略，并给出 `BackfaceOmittedWarning`（GUI 接口返回 `omitted_backface` 计数）。

### 5.3 复合地形 `terrain`

复合地形模型把地形表示为高度、半径和密度定义的锥体单元集合，计算地形遮挡、可视比例和日照/阴影比例。裸地使用 `Terrain`；`hom`、`row`、`crown` 使用 `TerrainForest`。锥面坡度 β=atan(h/r)，冠层在面元局地坐标中计算；该分支的 LAI 与株密度按水平面积计，面元参数取 `lai·cosβ`、`std·cosβ`。自遮挡按面元朝向处理，他山遮挡单独计入。

当前 `standard` / `upgrade` 的短波一次散射采用热红外同一套可见四组分（平面 + 锥面面元，局地几何），每个可见平面/坡面冠层的高阶散射用节点辐射度；再叠加现有宏观地形单次交换，该项是近似，不保证整个复合地形严格守恒。热红外使用相应级别的四组分直接项和节点散射，再参与地形交换；`forest_transport` 缺省仍为 `legacy`。

`optical_terrain_method=reciprocal_exchange/facet_exchange/finite_crown_ports` 的不同专用实现主要属于 `canopy_closure=legacy`；标准冠层会路由至共用面元冠层适配器，不能仅凭这些历史选项名称认定执行了旧四状态或显式网格算法。`effective_slab` 是显式替代路径，需另行验证。旧热红外 `forest_transport=reciprocal_exchange` 为可选四状态互易交换，当前要求 `canopy_closure=legacy`。

历史报告中的地形红光/近红外 RMSE 和运行速度只对应其当时版本及选项，不能直接作为当前修正闭合的精度；本版本前后对比统一见 [修正报告](validation/physics_corrections_20261026/report.md)。

参数支持分号数组，例如多层地形：

```text
terrain_height = 10;20;30
terrain_radius = 5;10;15
terrain_density = 0.001;0.0005;0.0002
```

### 5.4 城市 `urban`

城市模型把建筑表示为长度、宽度、高度、密度和方位角定义的建筑单元，区分屋顶、墙体、街道的可见和日照/阴影贡献，可与 `hom`、`row`、`crown` 组合。建筑占地比例 `Σ density·length·width` 必须小于 1。所有方位角差统一折叠到 [0°, 180°]，建筑方位 0° 与 360° 等价，镜像几何给出相同结果。

### 5.5 地形与城市的多次散射

地形单元和建筑之间的发射—反射交换按布尔随机场（Boolean field）处理：

- 地形单元的上/下半球交换使用朗伯视因子加权，交换比例已截断归一（近地平线方向不出现负分量）。裸地中，山体发射经坡面和地面反射、地面发射经坡面反射，各自使用发射组分和反射组分自己的发射率。
- 散射墙体发射的日照份额按路径区分：墙—墙路径由发射面元的朝向（是否朝向太阳）与接收面元的视因子推导，经地面/屋顶反射的路径取朝向平均，再乘以面元间的相互遮阴因子。
- 植被与宏观交换分层计算：标准热红外使用四组分与节点内部散射（4.5 节），标准短波使用共同守恒角算子（4.6 节）；锥面采用局地角度与 `lai·cosβ`，城市冠层位于街道边界并受建筑阴影影响。随后才参与地形/建筑交换。零地形或建筑密度在公共入口退化为对应平地冠层；局地冠层证明不替代宏观交换验证。

城市热红外的 `urban_transport` 缺省值依冠层级别确定：`standard` / `upgrade` 默认 `radiosity`，`legacy` 默认 `legacy`，显式设置仍可覆盖。`radiosity` 使用街道 + 四面墙的朗伯节点求全阶交换（[urban_radiosity.py](../base/urban_radiosity.py)），视因子与光学城市共用，满足面积互易；各节点按自身面积平均的日照比例发射，等高屋顶只对天空。街道冠层作为混合边界处理，其内部散射保留相应冠层闭合；目前只支持单一建筑类。这里的宏观辐射度开关与 `canopy_closure` 的局地几何/散射级别应分别记录。历史城市 HiSTREAM 分数仅代表其保存参数和版本，当前修正结果见 4.7 节所链接的报告。

## 6. 波段与光谱

光学和热红外共用一张波段参数表，保证同一材料在两个谱段的参数自洽。每行一个参数，分号分隔，每个波段一个值：

```text
wavelengths        = 0.67;0.86;10.5
leaf_reflectance   = 0.05;0.45;0.015
leaf_transmittance = 0.03;0.40;0.0
soil_reflectance   = 0.12;0.25;0.045
street_reflectance = 0.12;0.18;0.045
wall_reflectance   = 0.20;0.25;0.07
roof_reflectance   = 0.15;0.20;0.05
```

小于 2.5 µm 的波段用该波段的反射率、透过率计算光学 BRF；大于等于 2.5 µm 的波段按基尔霍夫定律得到发射率：

```text
ε_leaf = 1 − ρ_leaf − τ_leaf
ε_soil = 1 − ρ_soil（复合地形山体与土壤同一材料）
ε_street = 1 − ρ_street，ε_wall = 1 − ρ_wall，ε_roof = 1 − ρ_roof
```

上面的默认值在 10.5 µm 给出 ε_leaf = 0.985、ε_soil = 0.955、ε_street = 0.955、ε_wall = 0.930、ε_roof = 0.950。叶片反射率 + 透过率不能超过 1。`spectral_source=file` 时从 `spectrals_file` 读取同样顺序的 7 行表（第一行为波段，每行前面可带文字标签，`#` 之后为注释）。场景用不到的行可以省略：裸地不需要叶片行，非城市场景不需要街道/墙壁/屋顶行，城市场景不需要土壤行。

## 7. 观测几何

`geometry_mode` 控制观测方向来源：

- `0`：使用 `vza` 和 `vaa` 的笛卡尔组合或 zip 配对。
- `1`：自动生成太阳主平面和垂直主平面。
- `2`：从 `geometry_file` 读取观测方向。
- `3`：生成主平面方向，并可追加半球方向、文件方向或手动方向。

几何文件每行支持：

```text
vza vaa
vza vaa sza saa
```

角度单位均为度。

## 9. 数值稳定处理

为避免奇异几何造成无效输出，模型对若干边界情况做了保护：

- 天顶角接近 0 或 90 度时，内部计算使用有限角度近似；太阳与观测都垂直时阴影重叠比取 0。
- 城市 nadir 观测中，观测方位物理上无定义，内部统一到太阳方位，避免虚假的方位差异。
- 坡面背面观测会被省略并给出警告。
- 非有限的辐射或亮温不会输出到 GUI 和绘图模块。

## 10. 模型适用边界

TiRT 适合单点或小场景方向性辐射模拟，重点是结构和几何造成的方向性差异。球形叶倾角、有限温度组分、CI/泊松冠层、当前 crown2 粗化以及宏观单次交换等均是具体闭合假设。标准短波的互易性与局地能量控制通过，不意味着热红外所有非等温半球预算或复合地形/城市整体误差均已消除；固定组分温度下与 HiSTREAM 的比较，也不证明能量平衡预测温度正确。若用于大区域制图，还需准备逐像元输入、地表分类、组分温度反演及传感器谱响应等前处理，并在目标场景独立验证。

# 当前光学与热红外模型

本次代码将红光/近红外方向反射计算与热红外方向发射计算放在同一套场景与参数协议下验证。温度、发射率与光学反射/透射系数仍是不同的物理输入。

完整输入、30张图、逐方向HiSTREAM参考及精度统计见[2026-10-15验证](validation/current_model_20261015/README.md)。从项目根目录运行：

```bash
python scripts/verify_physics.py
python scripts/validate_current_model.py --plots
```

## 分支与配置

| 场景 | 当前实现 | 关键配置 |
|---|---|---|
| 均质植被 | 均质几何与光学直接/漫射输运，热红外保留对应发射源 | 见验证目录inputs |
| 平地垄行 | 条件化开放行间通道；保留对应光学和热红外源项 | `thermal_row_geometry=conditioned_corridor` |
| 平地/单坡森林 | 整冠内/外双热点与冠层组分合成 | `thermal_crown_geometry=clumping_dual`、`optical_crown_geometry=clumping_dual` |
| 复合山地森林 | 整冠几何与固定4状态互易交换 | `forest_transport=reciprocal_exchange` |
| 城市森林 | 森林内/外双热点乘入城市建筑遮挡；保留城市自身多次散射近似 | 热红外、光学分别选`clumping_dual` |

验证配置明确选择当前分支，未把同一交换矩阵强加给全部地表。原有`legacy`等模式仍可显式使用；`volume`并不属于当前整冠参数化方案，城市热红外拒绝该模式。

## 整冠内/外双热点

冠内宽度默认为输入的`hspot`；冠外宽度默认为树冠水平半轴与垂直半轴之比：

\[
w_{\rm inner}=h_{\rm spot},\qquad
w_{\rm outer}=R/h_{\rm cr}.
\]

可分别使用`thermal_hotspot_inner/outer`和`optical_hotspot_inner/outer`覆盖。`outer=0`用于关闭非重合方向的冠间重叠，是消融开关，不是删除冠层可见面积。内/外热点由整冠平均光程与投影重叠计算，当前分支不做冠体元积分。

当前山地采用“仅统一交换闭合”，**显式保留**`R/hcr`外宽。共享交换分支在未显式给外宽时另有冠心高度默认，因此复现该选择时应使用本次打包的完整输入，而非只设置输运开关。

## 山地统一交换

`base/forest_exchange.py`共用坡面土壤、坡面叶片、平地土壤、平地叶片4状态的几何、面积互易及求解器。设几何交换矩阵为\(F\)，反射/散射系数为\(a\)，直接来源为\(s\)：

\[
T=\operatorname{diag}(a)F,\qquad
L_{\rm higher}=(I-T)^{-1}Ts.
\]

光学叶片高阶采用\(a=\rho+\tau\)，土壤采用\(\rho_g\)；太阳首阶保留叶片反射/透射相函数。热红外采用\(a=1-\epsilon\)，来源由\(\epsilon B_\lambda(T)\)构造。两者共用几何，不交换物理源项。

此分支保留固定方向求积与小矩阵求解，并非完全无数值求积。光学高阶各向同性是近似，尤其可能影响近红外；离散状态预算守恒不代表整个BRDF半球角积分已严格验证。

## 城市森林

`Urban_Veg.set_hotspot_geometry('clumping_dual', inner, outer)`接入与其他森林相同的双热点组分概率。建筑太阳/观测遮挡仍由城市核计算；热红外以各自组分温度合成，没有添加光学经验增益。原城市光学本已使用双热点，本次只显式固定其宽度并验证有效，没有再次叠加热点函数。

城市仍为统计冠层与建筑耦合近似，未完整解析每棵树与建筑之间的三维输运。该城市案例61方向热红外RMSE从0.759506降至0.472191 K；红光与近红外保持0.009829与0.019612 BRF。此改进不等同于野外精度或所有城市布局的验证。

## 验证边界

当前包包含10组既有场景，复合山地替换为100 m高、100 m半径山体和2 m半轴球冠；0.9 m叶片森林及20 m小丘陵不参与当前排名。热红外是固定组分温度的方向辐射验证，不能据此宣称TIRTEB日变化能量平衡闭合。

`validate_current_model.py`只需要仓库中的输入和参考统计，不需要外部案例目录或HiSTREAM二进制。它重算1830条记录，显式标记24条单坡背面观测，并对1806条有效预测和同方向参考配对。冻结参考未重新生成，原始影像和引擎不在此验证包内。

# TiRT 1.1.1

修复 1.1 的时间模拟接口未连接到 EXE 主服务的问题。原 1.1 保留，修复版独立发布。

- 蓝色 **TIRT-Static / 静态场景**，红色 **TIRT-Dynamic / 动态场景**；动态页返回当前静态入口。
- 单一服务支持静态、时间序列及旧角度接口；EXE 包含动态输入和气象、光谱资源。
- 修复动态光谱上传字段、默认方向文件覆盖手动角度、角度成对输入被展开为交叉组合的问题。
- 修复动态冠径、冠高半轴、坡度、冠层高度和发射率与求解器的参数映射。
- 城市动态光学使用当前时间步实际的直射／漫射比例，避免将自动分配标记 `-1` 传入反射率计算。
- 缺失数值保留为空；界面显示能量平衡闭合步数及最大残差。

验证覆盖均质、垄行、森林、单坡森林、100 m 复合山地森林、城市森林的真实时间计算；同时检查上传光谱、观测角度、三波段输出及浏览器切换和绘图。实际 EXE 在移除 Python/Conda 路径后重跑上述接口，并复算原 10 场景、1830 条静态预测；HiSTREAM 参考保持冻结。

动态接口完成计算不等于各时间步能量平衡都闭合，`closed`、`iterations` 和 `energy_balance_residual_W_m2` 随结果保留。源码、EXE 和浏览器实测记录随发布提供。

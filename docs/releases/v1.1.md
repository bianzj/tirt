# TiRT 1.1

发布日期：2026-10-17。基于当前模型和10组场景光学/热红外验证构建的Windows x64单文件程序。

## 使用

下载GitHub v1.1发布中的TiRT.exe，放在任意可写目录，双击启动。默认打开本机浏览器，模型在本机计算；无需安装Python。界面退出按钮关闭服务。

```powershell
# 不自动打开浏览器
.\TiRT.exe --no-browser --port 8765
# 直接用exe复算内置的10组场景，包含热红外、红光与近红外
.\TiRT.exe --verify-model .\verification
```

验证模式保存all_results.csv、reference_comparison.csv、accuracy.csv和verification.json。1830条方向记录中1806条为有效预测，24条是单坡背面方向。有效预测与发布基准的绝对容差为1e-10；原HiSTREAM参考保持冻结。

## 当前模型

- 平地/单坡森林与城市森林使用已实现的整冠内/外双热点分支；城市光学原有外热点保留，不重复叠加。
- 100 m山地森林的发布验证配置采用仅统一交换闭合，外宽显式保持R/hcr。
- 垄行热红外包含conditioned_corridor；其他场景保留对应模型。各输入的实际选择可查[验证配置](../validation/current_model_20261015/inputs)。
- 热红外仍是给定组分温度的方向辐射结果，不能将其视为日变化能量平衡已闭合或野外精度验证。

## 从源码构建

在Windows Python环境安装PyInstaller和项目运行依赖，然后执行：

```powershell
python scripts/build_tirt_release.py
```

生成release/v1.1/TiRT.exe和build_info.json。Windows产品/文件版本为1.1.0，构建记录包含源码提交号和SHA256。构建不重新生成HiSTREAM光追。

构建后检查本机API /api/health、/api/version、静态界面、实际计算及输入导出；再使用exe验证模式复算全部场景。发布资产包含校验和与本次实测记录。

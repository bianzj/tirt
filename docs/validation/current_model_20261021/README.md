# 当前TIRT验证（2026-10-21，参数化标准）

本目录用当前代码和**默认分支**重算[2026-10-15验证](../current_model_20261015/README.md)的10组场景、三个波段（10.5 μm、670 nm、860 nm）。HiSTREAM参考、几何、组分温度、发射率和光学材料均沿用上一版，未重新运行光线追踪。

当前标准（`run.py`、GUI、`angle_run.py` 的默认值）：

- 森林 `thermal_crown_geometry=parametric`：泊松椭球冠的闭式四组分比例（`base/crown_parametric.py`），需要冠底高度 `crown_height`；
- 垄行 `thermal_row_geometry=parametric`：垄截面分段精确求和的闭式比例（`base/row_parametric.py`），平地、坡面、地形、城市共用；
- 复合地形：3 个高度带、10 个坡面方位、9 个半球天顶节点，`forest_transport=legacy`；
- 城市：墙—街交换半球 9×12 节点，3 个高度带。

红光/近红外只有复合山地因共用地形网格变化（最多 0.002 BRF；RMSE 670 nm 0.0055、860 nm 0.0084 BRF，与上一版相同），其余逐位不变。

## 热红外精度（K，相对HiSTREAM）

| 场景 | 2026-10-15 RMSE / 偏差 | 当前 RMSE / 偏差 | 耗时（ms/方向） |
|---|---|---|---|
| 平地裸土 | 0.000 / +0.000 | 0.000 / +0.000 | 0.01 |
| 平地均质冠层（LAI 1.5） | 0.199 / +0.168 | 0.198 / +0.164 | 0.18 |
| 平地离散森林（叶片 0.15 m） | 0.545 / +0.267 | **0.138 / −0.034** | 0.24 |
| 垄行（垄向 0°） | 0.288 / +0.165 | **0.128 / +0.000** | 0.58 |
| 垄行（垄向 90°） | 0.375 / +0.194 | **0.134 / −0.017** | 0.75 |
| 单坡 30° 朝东 + 均质冠层 | 0.262 / +0.233 | 0.260 / +0.226 | 0.33 |
| 单坡 30° 朝东 + 森林 | 0.549 / +0.247 | **0.140 / −0.019** | 0.29 |
| 复合山地 + 森林（100 m） | 0.478 / +0.344 | **0.178 / −0.160** | 0.84 |
| 城市（无植被） | 0.567 / +0.204 | 0.567 / +0.204 | 0.81 |
| 城市 + 森林 | 0.472 / +0.042 | 0.670 / +0.472 | 0.56 |

耗时为单波段、缓存预热后 61 个方向的平均。城市＋森林变差的原因：上一版城市分支没有冠层散射（约 −0.9 K），偏差接近 0 来自与城市核其余部分正偏差的抵消；平地森林场景表明这一散射量级本身是需要的。均质冠层与城市建筑核不在本次参数化范围内。

## 文件

- `inputs/`：实际使用的完整配置；`all_results.csv`：1830条波段—方向记录（24条单坡背面观测标为`slope_backface`）。
- `reference_comparison.csv`、`accuracy.csv`：与HiSTREAM的配对差值与统计；`accuracy_change.csv`：与2026-10-15版的对照。
- `result_ranges.csv`：各场景取值范围；`figures/`：30张三波段图（PNG/PDF）。
- `manifest.json`：输入与结果的SHA256、生成时的模型源码哈希。

## L 与温度共同迭代

不再固定使用中性大气。每个气象时间步继承上一时刻 L，以 `x=1/L` 作为稳定度未知量；给定 x 后重新求温度、气孔阻抗、空气动力学阻抗、阵风和组分通量，使用与输出相同面积基准的场景感热更新

```text
L = -rho·cp·Ta·ustar^3 / (kappa·g·H)
```

H 为正得到负 L，H 为负得到正 L，中性作为方程解允许 L 无穷大。形成符号区间后使用有保护的割线法；未形成区间时阻尼更新。内层最多 `max_iter=50` 次标量修正，外层最多 `max_stability_iter=60` 个试点。标量温度振荡时采用有界信赖域温度/H 后备；傍晚温度平衡分支切换使旧 L 区间失效时，联合求解温度、阵风 H 和 1/L。

每次数值雅可比求值都重置温度、阵风 H 和对应 L；不推进热历史。返回前重算实际通量，同时检查组分能量残差、阵风 H 一致性和

```text
abs(1/L - target) <= 1e-7 + 1e-6·abs(target)   [m^-1]
```

稳定订正对整个廓线统一限制有效倒数长度，再计算参考高度与粗糙度高度的差，避免强稳定时两个独立截断的 psi 项相消。实际由 H 求得的 L 保持不裁剪，`stability_zeta / stability_limited` 明确记录稳定订正适用范围限制；没有把限制状态换成中性结果。

## 其他完成的修正

- 城市：街道/冠层与四立面通过互易视因子求全阶交换，屋顶直接面向天空；等温黑体环境下组件净长波为零。街道土壤面积完整保留，叶片按真实叶面积另加，不使用天底覆盖率替代能量面积。总通量按水平地面面积积分，不再除以建筑总外表面积，也不再固定日照/阴影各一半。
- 地形：单坡修正水平直射的坡面投影、天空与下半球环境输入；复合地形使用裸露平面及 12 个圆锥方位面群体的统计遮阴、真实表面积与互易交换，不再按平地求温度。单坡通量按局地坡面面积；城市、平地和复合地形按水平地面面积。
- 导热：土壤采用质量比热×密度，城市采用已给定体积热容；隐式向后欧拉使用当前表面边界，不截断 Fourier 数。通量与提交剖面使用相同材料及同一个新剖面。48 小时热历史保留真实间隔，首步使用 dtime。
- 生理：光照/阴影叶分别使用各自温度和 PAR；叶面积阻抗按 LAI 转为整体阻抗。土壤支持 Sellers 含水量关系并保留显式常数输入。没有引入未经验证的水量闭合模型。
- 光谱：能量平衡的灰体宽带参数独立于观测波段数量，支持显式覆盖；不再对所选观测波段做算术平均来改变温度求解。
- 短波可行性：低太阳高度下，原固定直散比例在某些输入时刻对应不可能的直射法向功率。现在保留气象总短波，把超过日地距离修正的太阳辐射上限的部分转为漫射，记录实际比例和调整标记。该约束可显式关闭，未把它当成实际直散射测量。
- TiRT 短波：一次散射、半球逃逸和吸收预算采用共同节点算子；保留非负、互易的球形叶片相函数与热点角分布。热点和平衡求积的近似及精度限制见 [算法细节](optical_method_and_limits.md)。

## 必须保留的精度和理论限制

冻结的 10 场景、1830 条请求及 1806 条有效 HiSTREAM 配对重新计算完成；输入与参考哈希保持一致。原预测不是本轮新算法的冻结基准，`prediction_replay_passed=False` 如实记录算法变化。没有覆盖旧预测或参考曲线。

物理约束修复**不等于所有场景精度提高**。标准短波粗节点的逃逸预算限制了方向校正能恢复的精度；当前模型相对同一 HiSTREAM 参考存在退化：

| 场景/波段 | 原 RMSE BRF | 当前 RMSE BRF |
| --- | ---: | ---: |
| 平地均质 860 nm | 0.00746 | 0.01421 |
| 平地树冠 860 nm | 0.02140 | 0.05292 |
| 坡面树冠 860 nm | 0.02065 | 0.06385 |
| 复合地形树冠 860 nm | 0.02408 | 0.04190 |

全部场景、波段与最大差见 [accuracy_before_after.csv](accuracy_before_after.csv)，热点区另见 [hotspot_accuracy_before_after.csv](hotspot_accuracy_before_after.csv)。没有针对这些参考曲线拟合新系数。改变共享树冠节点方案的尝试会损害热红外等场景精度，未作为默认修改保留。因此本轮可以确认守恒/互易及数值耦合修正，但不能宣称树冠光学精度问题已经解决。

复合地形仍只有四个共享温度，采用统计面群体和灰体面间短波谱形近似，未成为 DEM 逐面温度模型。局地冠层的短波守恒/互易证明也不能自动外推为现有整个复合地形方向光学宏观闭合的严格证明。强稳定廓线受适用范围限制，生理胁迫和土壤水分仍主要由输入给定；未完成新增的独立实测验证。

## 复现

在项目根目录运行：

```powershell
python -m pytest -q
python validation/compare_tirt_tirteb.py --full
python validation/validate_current_model.py --allow-model-changes --output validation/results/physics_corrections_20261026
python tirteb_run.py --input input_tirteb.csv --output cases/physics_corrections_20261026/output.csv
```

默认严格复现入口仍保留旧结果差异检查；修正算法的对照需显式使用 `--allow-model-changes`。详细方程与输入约定见 [TIRTEB 理论说明](../../TIRTEB_theory_and_methods.md)和 [TiRT 理论说明](../../TiRT_theory_and_methods.md)。

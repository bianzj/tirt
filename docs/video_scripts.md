# TiRT 视频介绍脚本

## 01_overview_theory.mp4

主题：TiRT 是什么，以及热红外方向性模拟的基本理论。

镜头顺序：

1. TiRT 标题和用途。
2. 输入到输出的数据流。
3. 普朗克函数和反普朗克亮温。
4. 组分可见比例、发射率、温度叠加。
5. 支持场景：平面、坡面、地形、城市、植被。

## 02_gui_quick_start.mp4

主题：从打开 TiRT.exe 到完成一次默认模拟。

镜头顺序：

1. 双击 `TiRT.exe`。
2. 浏览器打开本地 GUI。
3. 保持默认参数，点击 `Run simulation`。
4. 查看结果区指标和三类图。
5. 保存 `observations.csv`。

## 03_scene_and_input_settings.mp4

主题：如何设置场景结构、角度、光谱和温度。

镜头顺序：

1. Surface mode 与 Vegetation type。
2. 坡面/地形/城市结构参数。
3. 主平面、半球和手动角度。
4. 直接光谱和文件光谱。
5. 日照/阴影温度。

## 04_results_export_distribution.mp4

主题：如何读结果、导出文件并分发程序。

镜头顺序：

1. Polar 图识别方向性冷热区。
2. Parallel/Perpendicular 曲线比较方位差异。
3. 切换波段和输出量。
4. 保存输入与输出。
5. 压缩 `dist` 目录发送给别人。
